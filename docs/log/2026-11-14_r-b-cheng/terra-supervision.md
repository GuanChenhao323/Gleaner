# YouTube HTTP / Playwright 独立监管记录

## 结论与范围

- HTTP-02 完成单次导入、13 轮真实 YouTube 内容请求，满足本次 7200 秒跨度及 600–640 秒相邻请求间隔要求。
- Playwright-01 在导入会话和发起内容请求之前被锁屏阻断，未通过长测。顺序对照因此未完成，无法据此比较两种后端。
- 本次新增真实长测只覆盖 YouTube HTTP 主文档响应与模拟接收链路。Moodle 和 Bilibili 无新增真实验证；网页内容提取和新视频发现不在本次结论范围内。

以下核对基于脱敏状态和各自 JSONL，未读取认证页面、凭据、浏览器状态或剪贴板。三个运行的记录没有拼接。关于锁屏原因和 HTTP-01 DNS 具体阻断原因，下文明确标注来自主代理的转述。

- robots / TLS：无 robots 请求记录和 TLS 握手或证书记录，不能从该组判断 robots 或 TLS 成功。
