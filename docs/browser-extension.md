# 浏览器插件（M12）

2026-10-26 组长提出的新需求（决策第 15 条）：在 Chrome / Edge 上点一下插件，就能把当前页面加进拾课。

## 1. 功能

| 功能 | 用户操作 | 结果 |
| --- | --- | --- |
| 保存这个页面 | 点插件图标 →“保存到收件箱” | 插件当场读取页面标题、网址、正文（有选中文字时只取选中部分），作为一条“收藏”事项进入收件箱；同一网址再次保存会记录新版本 |
| 订阅这个页面 | 点插件图标 →“订阅更新” | 把网址加为信息源，拾课定期检查；页面内容变化时推送（整页监测，可限定关注区域）。页面带 RSS 时优先订阅 RSS |

需要登录才能看的页面：“保存”不受影响（内容在用户浏览器里读取）；“订阅”时服务器取不到内容，来源会显示“需要登录 / 检查失败”，
这类页面需配合本地采集代理（`agent/`），插件会提示。

## 2. 组成

| 部分 | 位置 | 说明 |
| --- | --- | --- |
| 插件 | `extension/` | Manifest V3，Chrome 与 Edge 共用一份代码；不受 server/ 的库限制 |
| 保存接口 | `POST /api/clips` | 每个用户一个个人来源“网页收藏”（类型 `clip`，不参与定时采集）；事项类型 `clip`，走正常的去重、版本、打分、实时推送 |
| 订阅接口 | `POST /api/sources`（已有） | 类型 `web`，`config.mode = "page"` 为整页监测；类型 `rss` 订阅页面声明的 RSS |
| 整页监测 | `collector/connectors/web.py` | 整页（或 `config.region` 指定的区域）作为一个事项，正文变化产生新版本 |

## 3. 权限与隐私

- `activeTab` + `scripting`：只在用户点击图标时读取当前标签页，不申请“读取所有网站”。
- 拾课服务器地址在插件设置里填写，只对这一个地址申请访问权限（`optional_host_permissions` 运行时申请）。
- 插件用拾课账号登录，保存的只是登录令牌（`chrome.storage.local`），不保存密码；可随时在插件里退出。
- 正文上限 100 000 字，超出截断；不上传页面截图、Cookie 或表单内容。

## 4. 安装与发布

- 开发 / 内测：`chrome://extensions`（Edge 为 `edge://extensions`）打开“开发者模式”→“加载已解压的扩展程序”→ 选择 `extension/` 目录。
- 上架：Chrome 网上应用店需要开发者账号（一次性注册费，以官网为准）；Edge 加载项需要微软合作伙伴账号。由组长注册后再提交。
