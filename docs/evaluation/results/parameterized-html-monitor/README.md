本目录只保存脱敏的请求、认证结论、内存接收替身回执和运行摘要。Cookie、密码及完整 HTML 不写入报告。时间为 UTC；各 JSONL 的 `run_id` 独立，不能把不同运行的轮次拼接成连续通过。

真实运行期间本包改动尚在工作区；旧调试入口报告中的 `commit` 仅是当时的 Git HEAD，不能证明运行源码与该提交完全一致。各次运行使用的差异以本表及原始记录为准。
