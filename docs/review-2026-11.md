# 2026-11 服务端全面审查与修复清单

2026-11-05 对服务端做了一次逐行审查（HTTP API、数据库与持久化、大模型调用、模块间通信），每条都在代码里核实过。
按批次修复，每批先写测试；`[x]` 已修复，`[ ]` 待修复，`[-]` 决定不改（写明原因）。
编号：API = HTTP 接口，DB = 数据库，LLM = 大模型，BUS = 总线与模块调用。严重程度：H 高 / M 中 / L 低。

## 第 1 批：接口健壮性（错误输入不再变成 500，500 不再把节点踢出）

- [x] API-1 H 坏 JSON / 非对象请求体 / 类型不对的字段 → 500；网关把 5xx 记为被动失败，连续 5 次摘除节点 → 几个坏请求就能让整个 API 503。改为 400/422，网关只把连接错误和 502/503/504 记为失败
- [x] API-2 H 路径 id 非数字、`int()`/`float()` 未校验（feed limit、deadlines、state ts、weight、boost、account_source_id 等）→ 500
- [x] API-5 H `state/batch` 一条坏操作让整批 500，离线队列永远卡住；超过 500 条被静默截断
- [x] API-9 M feed `limit=0` → 500，负数在 SQLite 上返回全部
- [x] API-10 M feed 游标与 SQL 排序键不一致（`published_at == 0` 时翻页跳过或重复）
- [x] API-21 M 并发注册同一邮箱 → 500
- [x] API-23 M 错误格式不统一（有的没有 code、有的 200 + ok:false、有的回显原始输入）
- [x] API-27 L 不传 `agree_privacy` 视为同意

## 第 2 批：接口安全

- [x] API-8 M 没有 op_id 时不做“后写胜出”检查
- [x] API-11 M `/items/{id}/feedback` 不校验归属
- [x] API-12 M `/courses` 返回所有来源的教师事项（含别人的私有来源）
- [x] API-13 M 公共来源的配置与名称由第一个添加者决定；`via_agent` 会让公共来源永不采集

- [x] API-16 M 没有按用户的数量上限与请求体大小上限（已加：每人 200 个来源、看板 32 KB、规则 200 条、发信 20 个收件人、传输每次 50 个文件 / 2 GB；请求体总上限仍是服务端统一的 32 MB）
- [x] API-17 M 删除账号不是原子操作、不删磁盘上的传输文件、不要求再次输入密码
- [x] API-18 M Cookie 缺 Secure；带 Cookie 的修改请求没有 CSRF 防护

- [x] API-20 M 验证码错误次数上限可被并发绕过

- [x] API-24 M 扫码传输：配对码可反复换取令牌、整文件读入内存、文件数不设上限
- [-] API-25 L `/agent`、`/mqtt` 等路由绕过网关限流（不改：两者都是长连接升级，鉴权后由推送节点 / Broker 自己限连接数；按请求限流不适用）
- [x] API-26 L `/api/stats`、`/gateway/status`、`/metrics` 对外公开（`/api/stats` 需管理令牌；网关的 `/metrics`、`/gateway/status` 只放行直连地址为内网的请求或带 `X-Admin-Token` 的请求。注意 Docker 用 docker-proxy 转发端口时外部请求也显示为网桥地址，生产环境应在反向代理上屏蔽这两个路径）
- [x] API-29 L `update_me` 接受 `99:99`；weight 未夹紧；LIKE 通配符未转义且两种数据库大小写行为不同

- [x] API-32 L 出错日志里带查询串中的令牌

## 第 5 批：总线与模块调用

- [ ] BUS-1 H Hub 在读循环里同步执行处理器（入库 + 大模型），一次慢处理 > 15 秒就把采集节点判为下线并触发重新分配与告警
- [ ] BUS-2 H 节点离线超过 60 秒后成员被删除、序号从 0 重来，客户端去重表不清 → 之后收到的帧全部被当成重复丢弃
- [ ] BUS-3 H 送达只保证到 ACK：入库失败或 core 宕机时，采集端已记下内容哈希，这批事项永远不会再入库

- [ ] BUS-5 M 编码失败（超过 16 MiB）会让心跳 / 维护任务永久退出
- [ ] BUS-6 M NODE_JOIN 无认证，任何能连上 7400 端口的进程可冒充节点、订阅全部用户消息
- [ ] BUS-7 M “立即检查”在没有采集节点时也返回成功
- [ ] BUS-8/9/12 L 文档与实现不符；重连后已取消的订阅可能恢复
- [ ] BUS-10 L 解压没有大小上限
